# GYH · 典藏画册

个人静态主页，部署于 gyhcookingmenu.space。一本杂志式画册，五个主题房间：

| 卷 | 模块 | 主题 |
|---|---|---|
| 一 | 赛道竞速（F1 / GT3） | 车库 GARAGE |
| 二 | 性能街车（AMG / BMW M / Audi RS / GTI / 超跑 / 沃尔沃） | 展厅 SHOWROOM |
| 三 | 公路自行车（近两年旗舰） | 车队 PELOTON |
| 四 | 摄影（尼康微单 / 胶片相机 / 个人作品） | 画廊 GALLERY |
| 五 | 观赏鱼（灯科鱼 / 异形鱼 / 南美缸） | 水族馆 AQUARIUM |

## 技术栈

Vite + React 18 + Tailwind CSS v4 + GSAP（ScrollTrigger / Lenis 平滑滚动）+ [React Bits](https://reactbits.dev) 组件（SplitText / Magnet / CountUp / GlareHover / SpotlightCard / ShinyText）。

## 本地开发

```bash
npm install
npm run dev      # 开发预览
npm run build    # 产出 dist/
npm run preview  # 本地预览构建产物
```
