# V8 曲柄连杆机构 · 三维运动与拆解

单文件、离线可运行。模型为 CGTrader 免费资源 **V8_Engine_V3.glb**（8.33 MB，25 网格 / 18,614 面 / 9 张 2K PBR 贴图），已 Base64 内嵌进 HTML，页面不发任何外部请求。

## 打开

双击根目录的 `V8-crank-train.html`（约 11.8 MB）。首次打开会有 1–2 秒解码，属正常。

| --- | --- |
| 左键拖动 / 滚轮 / 右键拖动 | 旋转 / 缩放 / 平移 |

底部：拆解滑块 0–100%，以及「全部拆解 / 活塞组 / 连杆组 / 曲轴飞轮」快捷筛选。
右侧：结构原理、零件清单、实测参数（行程、面数、贴图、体积均由文件直接测出）。

## 关于模型

这份 GLB **只有曲柄连杆机构**：曲轴 + 飞轮 + 8 活塞 + 8 连杆 + 8 连杆盖，没有缸体、缸盖、凸轮轴与气门。所以页面定位为「机构运动演示」，不做剖切与配气。

- 自带 12 秒烘焙动画：曲轴 2 圈（60°/秒），8 个 Aim_locator 驱动活塞、8 根连杆独立旋转。
- 播放器未使用 three.js 的 AnimationMixer，而是自己解析 glTF 的 animation samplers（线性插值 + 四元数 slerp），以便精确控制时间与拆解叠加。
- V 角约 40°（模型原样），不是 90°。

## 构建

```bash
cd v8glb
node build.mjs            # 读取 ../model/V8_Engine_V3.glb 并生成 V8-crank-train.html
```

源码：`src/app.js`（GLB 解析 / 动画 / 交互）、`src/ui.html`、`src/style.css`。换模型只需替换 `model/` 里的 GLB 并重新构建；若新模型的分件命名不同，改 `classify()` 与 `PART_INFO` 即可。

## 已知

- 模型材质本身是深色金属，页面把 metalness 限制在 0.92、roughness 下限 0.36，避免纯镜面发黑。
- 行程 204 mm 是按「模型单位为米」换算的；模型本身没有标注单位，若原始单位不同，该数值需按比例修正。
